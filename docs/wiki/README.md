# Ảnh và nội dung cho GitHub Wiki

Thư mục này chứa ảnh sơ đồ dùng trên [wiki của dự án](https://github.com/Longg5048/flower.com/wiki).

| File | Dùng ở |
| --- | --- |
| `Home.md` | Nội dung trang **Home**: mở wiki → Edit → dán toàn bộ file này → Save page |
| `kien-truc.png` | Sơ đồ kiến trúc tổng quan |
| `luong-mua-hang.png` | Sơ đồ 5 bước mua hàng |
| `vong-doi-don.png` | Sơ đồ trạng thái đơn hàng |

Wiki hiện ảnh bằng đường dẫn `https://raw.githubusercontent.com/Longg5048/flower.com/main/docs/wiki/<tên-file>.png`, nên **không đổi tên hay xóa** các file ảnh này. Muốn thay ảnh thì ghi đè file cùng tên.
